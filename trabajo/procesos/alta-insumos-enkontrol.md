# Proceso: alta de insumos en Enkontrol
Enkontrol = sistema (ERP) donde se dan de alta los insumos.

1. Se hace la solicitud de alta
2. Se espera a **Cristal (contabilidad)** -> ESPERA: registrar fecha de seguimiento
3. Cristal da de alta el insumo
4. (por aprender) ¿qué se puede hacer solo después del alta? ¿Comprar, pedir, registrar entrada?

Por aprender: por qué medio se le solicita a Cristal, y cuánto suele tardar.
